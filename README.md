# Temporizador

Página simples de múltiplos temporizadores exclusivos, publicada com GitHub Pages.

## Funcionalidades

- **Adicionar temporizador**: crie quantos temporizadores precisar com nome opcional.
- **Contagem exclusiva ao clicar**: clique em um temporizador para iniciar a contagem; ao clicar em outro, o anterior para automaticamente e o novo passa a contar (clicar no ativo pausa).
- **Arquivar**: mova temporizadores concluídos para a seção de arquivados (com opção de restaurar ou excluir).
- **Exportar**: baixe seus dados em **JSON** ou **CSV**.
- **Persistência local**: salva automaticamente no `localStorage` do navegador.
